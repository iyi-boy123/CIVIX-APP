# CIVIX — Community Issue Reporting System

CIVIX is a community issue reporting application that allows users to report problems such as bad roads, electricity outages, water supply issues, and sanitation concerns.

## Features
- User registration and login
- Community issue reporting
- Issue status tracking
- Database-backed issue storage

## Technology
- Frontend: HTML, CSS, JavaScript / React (as configured in the project)
- Backend: Node.js and Express
- Database: MySQL

## Running locally
1. Install the dependencies using `npm install`.
2. Configure your local environment variables in `.env`.
3. Start the server using the start command configured in `package.json`.

## Security
Keep `.env` and other secrets private. Do not commit credentials to GitHub.
